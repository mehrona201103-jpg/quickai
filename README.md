# QUICK AI — бот с сигналами и WebApp

## Файлы
- `bot.py` — бот, админка, API, постбэк
- `engine.py` — Heikin Ashi, индикаторы, подтверждение на старшем таймфрейме, фильтр новостей
- `db.py` — база SQLite (пользователи, сигналы, статистика)
- `webapp/index.html` — терминал в Telegram WebApp

## Запуск на Railway
1. Загрузите ВСЕ файлы в GitHub-репозиторий (без `.env`), Railway задеплоит автоматически.
2. **База данных:** в сервисе нажмите **Settings → Volumes → New Volume**, mount path `/data`.
   Без Volume база стирается при каждом деплое.
3. **Variables** (см. `.env.example`):
   - `BOT_TOKEN`, `TWELVE_API_KEY`, `CHANNEL_USERNAME`
   - `WEBAPP_URL` — ваш домен Railway с `https://`
   - `ADMIN_IDS` — ваш Telegram ID (узнать у @userinfobot), несколько через запятую
   - `DB_PATH=/data/quickai.db`
   - `DAILY_LIMIT=10`
4. Бот должен быть админом в канале (для проверки подписки).

## Админка
Команда `/admin` (только для `ADMIN_IDS`): статистика воронки, сигналов и процента плюсовых, рассылка всем или только тем, кто внёс депозит.

## Автопроверка депозита (postback)
Если в партнёрском кабинете Pocket Option есть постбэки:
1. Укажите URL: `https://ВАШ-ДОМЕН/postback?secret=ВАШ_СЕКРЕТ&uid={ПАРАМЕТР_ИЗ_ССЫЛКИ}&event=deposit&sum={СУММА}`
   (названия макросов смотрите в кабинете партнёра).
2. Переменные: `POSTBACK_SECRET=ваш_секрет`, `REG_SUBID_PARAM=` имя параметра, который партнёрка возвращает
   в постбэке (бот добавит `?параметр=ID пользователя` к ссылке регистрации).
3. `POSTBACK_REQUIRED=1` — тогда кнопка «Депозит готов» не даёт доступ без подтверждения.
По умолчанию `POSTBACK_REQUIRED=0`: доступ открывается по кнопке.

## Локальный тест WebApp без Telegram
`DEV_MODE=1` отключает проверку авторизации. На Railway обязательно `DEV_MODE=0`.

## Ограничения
- Бесплатный Twelve Data: 8 запросов в минуту. Данные кэшируются на 20 секунд; для большого числа пользователей нужен платный тариф.
- Календарь новостей берётся из открытой ленты Forex Factory; если она недоступна, фильтр новостей временно не работает.
- Результат сделки считается по котировкам Twelve Data и может отличаться от Pocket Option.

## Дополнительно
- Крипта (BTC, ETH): свечи берутся с Binance (без ключа), в приложении цена идёт живым потоком тиков Binance. Если Binance недоступен, используется Twelve Data.
- Результат сделки приходит сообщением в бот, если приложение было закрыто.
- Ежедневный отчёт админам в `REPORT_HOUR_UTC` (по умолчанию 16:00 UTC, это 21:00 по GMT+5).
- После 3 минусов подряд приложение советует сделать перерыв. Звук включается и выключается значком 🔊.

## Тарифы и оплата
- После выдачи доступа пользователь получает `FREE_SIGNALS` (10) бесплатных сигналов. Сигнал WAIT не списывается.
- За каждого приглашённого друга, получившего доступ, пригласившему даётся `REF_BONUS` (2) сигнала.
- **Pro** (`PRO_DAYS` дней, безлимит; защитный потолок `PRO_DAILY_CAP` в сутки): оплата звёздами или через CryptoBot.
- **Звёзды:** пользователь нажимает «Оплатить Telegram Stars», бот отправляет его в ваш чат (`OWNER_USERNAME`).
  Он отправляет подарки на 250 ⭐ и присылает ID. Нажав «Я отправил подарки», он создаёт заявку:
  вам в бот приходит сообщение с кнопкой «Выдать Pro». Проверить подарки бот не может, это делаете вы вручную.
- **CryptoBot:** создайте приложение в @CryptoBot (Crypto Pay), впишите токен в `CRYPTOBOT_TOKEN`.
  Бот создаёт счёт на `PRO_PRICE_USDT` USDT и сам включает Pro после оплаты (проверка раз в 20 секунд).
  Для проверки без денег: `CRYPTOBOT_TESTNET=1` и токен из @CryptoTestnetBot.
- За 3 дня до конца Pro и после окончания пользователь получает сообщение с кнопками продления.

## Команды админа
`/admin` (меню), `/grant ID|@username [дней]`, `/revoke ID|@username`, `/credits ID|@username N`,
`/user ID|@username`, `/pros`. В меню `/admin`: статистика с выручкой, Pro-пользователи, поиск, платежи, рассылка.

## Экспирация
В терминале можно выставить любое время от 1 минуты до 4 часов (пресеты M1, M3, M5, M15, M30, H1, H4).
Секундные экспирации не поддерживаются: для анализа нужны минимум минутные свечи.

## OTC-пары (OTCharts)
Источник: otcharts.com, книга `otc` = Pocket Option. Впишите ключ в Railway: `OTCHARTS_KEY`.
- `OTC_PAIRS`: список через запятую в формате «EUR/USD OTC» (это `EURUSD_otc` у OTCharts). Каталог вашего ключа и выплаты показывает команда админа `/otcsymbols`.
- Бесплатный ключ: 200 запросов в первый месяц, 5 инструментов, без живого стрима. Для боевой работы нужен тариф Lite ($15 в месяц: 7 000 запросов в день и стрим), Build даёт до 10 инструментов в стриме.
- Свечи кэшируются на `OTC_TTL` секунд, дневной потолок запросов `OTC_DAILY_BUDGET`. Живая цена идёт одним стримом на все пары.
- Для OTC-пар фильтр экономических новостей отключён: это синтетические котировки брокера.
